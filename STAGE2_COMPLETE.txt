## Key Debugging Lessons

1. **Standard library name conflicts** — never name files after stdlib modules (`collections.py`, `json.py`, `os.py`)
2. **`python -m` vs `python file.py`** — use `-m` for modules that import from other modules
3. **`try`/`except` variable scoping** — both branches must assign the same variable
4. **Regex matching in `pytest.raises`** — size matters; use `(?i)` for case-insensitive
5. **`git add .`** — stage everything; don't forget files
6. **VS Code nested folder bug** — always type ONLY the filename in "New File"
7. **Indentation is structural** — not cosmetic
8. **Test structure matters** — every `def test_...` needs a body
