# DSA Practice

LeetCode solutions for interview prep. Part of my transition from IT
Support into QA Engineering and Software Engineering.

## How I work

For every problem:

1. Read the problem — 2 min
2. Try to solve it myself — 15 min (no solution)
3. Stuck? Look at hints, not the solution — 5 min
4. Still stuck? Read the solution, understand it — 10 min
5. Close the solution, re-write from scratch — 10 min
6. Explain it out loud (or in comments) — 5 min

Every file contains: docstring, solution function, tests, complexity.

Run: `pytest dsa_practice/ -v`

## Folder structure

Problems grouped by pattern (NeetCode 150 order):

- `arrays/` — Two Sum, Contains Duplicate, Valid Anagram, Group Anagrams
- `two_pointers/` — Valid Palindrome, 3Sum
- `sliding_window/` — Longest Substring, Best Time to Buy/Sell Stock
- `stacks/` — Valid Parentheses, Min Stack
- `binary_search/` — Binary Search, Rotated Array
- `linked_lists/` — Reverse, Merge, Cycle
- `trees/` — Invert, Max Depth, Level Order
- `dynamic_programming/` — Climbing Stairs, House Robber, Coin Change
